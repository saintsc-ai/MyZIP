# MyZIP 사용법

## 설치

### 설치 마법사 (권장)

[Releases](https://github.com/saintsc-ai/MyZIP/releases) 에서
`MyZIP-1.0.0-setup.exe` 를 받아 실행하세요.

관리자 권한이 필요 없습니다. `%LOCALAPPDATA%\Programs\MyZIP` 에 설치되고
UAC 창이 뜨지 않습니다.

설치 중에 세 가지를 고를 수 있습니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 탐색기 우클릭 메뉴 | 켜짐 | 파일·폴더 우클릭에 MyZIP 추가 |
| 압축 파일 연결 | 켜짐 | `.zip .tar .tgz .rar .7z` 더블클릭 시 MyZIP 으로 열기 |
| 바탕 화면 바로 가기 | 꺼짐 | |

### 포터블 (설치 없이)

`MyZIP-1.0.0-portable.zip` 을 아무 곳에나 풀고 `MyZIP.exe` 를 실행하세요.

탐색기 통합까지 쓰려면 한 번만 등록합니다.

```
MyZIP.exe --register
```

폴더를 옮겼다면 `--register` 를 다시 실행하세요. 등록 정보에 절대 경로가
들어가기 때문입니다. 되돌리려면 `MyZIP.exe --unregister`.

## 탐색기에서 쓰기

> **Windows 11 에서는** 우클릭 메뉴가 바로 보이지 않고
> **'추가 옵션 표시'** (또는 `Shift`+`F10`) 안에 들어 있습니다.
> Windows 11 이 기본 메뉴를 짧게 유지하려고 기존 방식의 메뉴를
> 한 단계 아래로 옮겼기 때문입니다.

### 파일이나 폴더를 압축할 때

우클릭 → **MyZIP 으로 압축**

| 메뉴 | 동작 |
| --- | --- |
| 압축하기... | 형식·강도·암호·저장 위치를 정하는 창이 뜹니다 |
| ZIP 으로 압축 | 묻지 않고 바로 `이름.zip` 생성 |
| TAR.GZ 로 압축 | 묻지 않고 바로 `이름.tar.gz` 생성 |

여러 개를 선택하고 눌러도 **하나의 아카이브**로 묶입니다.
이름은 파일 하나면 그 이름, 여러 개면 상위 폴더 이름을 씁니다.

같은 이름이 이미 있으면 덮어쓰지 않고 `이름 (2).zip` 으로 만듭니다.

### 압축 파일을 풀 때

압축 파일 우클릭 → **MyZIP**

| 메뉴 | 동작 |
| --- | --- |
| MyZIP 으로 열기 | 풀지 않고 안을 들여다봅니다 |
| 여기에 압축 풀기 | 지금 폴더에 그대로 쏟아냅니다 |
| 압축 풀기 (폴더 생성) | 아카이브 이름의 폴더를 만들어 그 안에 풉니다 |
| 압축 풀기... | 위치와 옵션을 정하는 창이 뜹니다 |
| 무결성 검사 | 파일이 깨지지 않았는지 확인합니다 |

이 메뉴는 **기본 연결 프로그램이 MyZIP 이 아니어도** 나옵니다.
다른 압축 프로그램을 계속 쓰면서 MyZIP 을 곁들여 쓸 수 있습니다.

## 프로그램 화면

### 아카이브 들여다보기

![메인 창](images/myzip-main-subfolder.png)

압축을 풀지 않고 안을 폴더처럼 돌아다닐 수 있습니다.

- 왼쪽 트리에서 폴더 이동, 목록에서 폴더를 더블클릭해도 들어갑니다
- `Backspace` 로 상위 폴더
- 파일을 더블클릭하면 임시 폴더로 꺼내 연결된 프로그램으로 엽니다
- 열 머리글을 눌러 정렬 — 크기는 숫자로 비교하므로
  `9 KB` 가 `10 MB` 위로 올라가는 일이 없습니다
- 원하는 항목만 골라서 우클릭 → **선택 항목 풀기**

### 한글 파일명이 깨질 때

오른쪽 위 **파일명 인코딩** 상자를 보세요.

MyZIP 은 아카이브를 열 때 파일명 바이트를 UTF-8 / CP949 / CP932 / GBK 로
각각 풀어 보고 가장 그럴듯한 것을 아카이브 단위로 고릅니다.
자동 판별 결과는 괄호 안에 표시됩니다 (`자동 (한국어 (CP949))`).

그래도 깨져 보이면 목록에서 인코딩을 직접 고르면 즉시 다시 읽습니다.

> 왜 필요한가: ZIP 규격에는 파일명 인코딩을 적는 자리가 없습니다.
> 예전 한국 프로그램들은 CP949, 일본은 CP932 로 그냥 써 넣었기 때문에
> 만든 곳을 모르면 추측할 수밖에 없습니다.

### 압축하기

![압축 대화상자](images/myzip-compress.png)

- **압축 강도** — 표준(6)이 속도와 크기의 균형입니다.
  이미 압축된 파일(mp4, jpg, 다른 zip)만 담을 거라면 `저장`이 훨씬 빠릅니다.
- **암호** — ZIP 에서만 됩니다. AES-256 으로 암호화합니다.
  TAR 계열은 형식 자체에 암호 기능이 없습니다.

작업 중 취소하면 반쪽짜리 파일이 남지 않습니다.
임시 이름으로 만든 뒤 다 끝나야 제 이름으로 바꾸기 때문입니다.

### 압축 풀기

![압축 풀기 대화상자](images/myzip-extract.png)

- **중복 폴더 만들지 않기** — `자료.zip` 안에 `자료` 폴더 하나만 있을 때
  `자료/자료/...` 로 두 겹이 되는 것을 막습니다.
- **같은 파일이 있으면** — 덮어쓰기 / 건너뛰기 / 다른 이름으로 저장.
  기본값은 다른 이름으로 저장이라 기존 파일이 사라지지 않습니다.

### 설정

![설정](images/myzip-settings.png)

확장자 연결을 체크박스로 켜고 끕니다. 지금 그 확장자를 어떤 프로그램이
쥐고 있는지도 함께 보여 줍니다.

## 확장자 연결이 안 바뀔 때

설정 화면에 **"Windows 가 고정"** 이라고 노랗게 표시되면,
Windows 의 기본 앱 설정이 다른 프로그램으로 잠가 둔 상태입니다.

Windows 8 부터 프로그램이 사용자 몰래 기본 앱을 바꾸지 못하도록
`UserChoice` 레지스트리 키에 해시 서명을 걸어 두었습니다.
어떤 압축 프로그램도 이것을 우회할 수 없습니다.

**Windows 기본 앱 설정 열기** 버튼을 눌러 직접 MyZIP 을 고르세요.
(설정 → 앱 → 기본 앱 → 파일 형식별 기본 앱 선택)

우클릭 메뉴는 이 제약과 무관하게 그대로 동작합니다.

## 형식별 지원 범위

| 형식 | 압축 | 해제 | 비고 |
| --- | --- | --- | --- |
| ZIP | O | O | AES-256 암호 지원. 구형 ZipCrypto 는 읽기만 |
| TAR | O | O | |
| TAR.GZ / TGZ | O | O | |
| TAR.BZ2 / TAR.XZ | O | O | |
| GZ / BZ2 / XZ (단일 파일) | — | O | tar 로 감싸지 않은 것도 열립니다 |
| RAR (RAR4 / RAR5) | X | O | 아래 설명 |
| 7Z | X | O | |
| CAB / ARJ / LZH / ISO | X | O | |

### RAR 압축이 없는 이유

RAR 은 RARLAB 의 독점 형식이고 압축 알고리즘의 공개 구현이 없습니다.
7-Zip 이 쓰는 unRAR 소스의 라이선스는 그 코드를 **RAR 압축기 제작에
사용하는 것을 명시적으로 금지**합니다.

그래서 7-Zip 도, 반디집도, MyZIP 도 RAR 은 해제만 지원합니다.
RAR 을 만들려면 RARLAB 의 WinRAR 을 사야 합니다.

### RAR / 7Z 이 안 열릴 때

이 두 형식은 7-Zip 엔진(`7z.exe`, `7z.dll`)이 필요합니다.
배포판에는 함께 들어 있지만, 소스에서 직접 돌린다면 받아야 합니다.

```
python tools/fetch_7zip.py
```

설정 → 탐색기 통합 탭에서 엔진을 찾았는지 확인할 수 있습니다.
엔진이 없어도 ZIP / TAR / TGZ 는 완전히 정상 동작합니다.

## 명령줄

설치하면 `%LOCALAPPDATA%\Programs\MyZIP\MyZIP.exe` 에 있습니다.

```
MyZIP.exe <파일>                     아카이브 열기
MyZIP.exe --extract-here <파일>      같은 폴더에 바로 풀기
MyZIP.exe --extract-to <파일>        이름 폴더를 만들어 풀기
MyZIP.exe --extract <파일>           대화상자로 위치 정해 풀기
MyZIP.exe --test <파일>              무결성 검사
MyZIP.exe --compress <대상...>       압축 대화상자
MyZIP.exe --compress-zip <대상...>   바로 ZIP 으로
MyZIP.exe --compress-tgz <대상...>   바로 TAR.GZ 로
MyZIP.exe --password <암호>          암호 지정 (다른 옵션과 함께)

MyZIP.exe --register        확장자 연결 + 우클릭 메뉴 등록
MyZIP.exe --register-menu   우클릭 메뉴만 등록
MyZIP.exe --unregister      모두 해제
```

### 무인 설치 / 제거

```
MyZIP-1.0.0-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART "/TASKS=shellmenu,fileassoc"

"%LOCALAPPDATA%\Programs\MyZIP\unins000.exe" /VERYSILENT
```

제거하면 확장자 연결이 이전 프로그램으로 되돌아갑니다.
설치할 때 원래 값을 백업해 두기 때문입니다.

## 안전 장치

- **경로 탈출 차단** — 아카이브 안에 `../../windows/system32/evil.dll` 같은
  경로가 들어 있어도 지정한 폴더 밖으로 나가지 않습니다.
  상위 이동, 절대 경로, 드라이브 문자, UNC 경로를 모두 무력화합니다.
- **Windows 예약 이름 처리** — `CON`, `PRN`, `LPT1` 같은 이름은
  앞에 `_` 를 붙여 만듭니다.
- **링크는 만들지 않음** — tar 안의 심볼릭·하드 링크는 대상 경로를 적은
  텍스트 파일로 남깁니다. Windows 에서 링크 생성은 권한이 필요하고
  악용될 여지가 있습니다.
- **레지스트리는 HKCU 만** — 시스템 전역을 건드리지 않습니다.
  제거하면 원래 상태로 돌아갑니다.
